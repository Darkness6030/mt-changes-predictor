Документация кода
=================

Проект состоит из трёх модулей: библиотека признаков и моделей ``transport_ml``
(она же ML HTTP-сервис), Backend ``transport_backend`` (приём NDTP, состояние,
API диспетчера) и статический UI на React (документация интерфейса — в
``frontend/README.md``).

Сквозные инварианты: признаки строит только ``transport_ml.features.FeatureBuilder``;
для точки ``T`` используются исключительно события с ``event_time <= T``; цель —
первое плановое посещение в окне ``(T+600, T+900]``; отсутствие прогноза публикуется
статусом, а не нулевой задержкой.
