# ML v1: результат первого обучения

Дата: 25.09.2026. Обучение действительно выполнено локально на Python 3.12.10,
CatBoost 1.2.10, CPU arm64, seed=42, 4 потока.
[Полные метрики](ml-v1-metrics.json), [manifest](ml-v1-manifest.json).

## Методика

1 141 реальная точка train; 3 293 синтетические исключены. Temporal development:
граница `2026-01-06 16:35:00`, fit 844, development 287, purged 10. Из fit исключены
не наступившие до границы исходы и точки с пересекающими границу окнами истории.
Использование target при вычислении времени доступности label относится только к split,
не к признакам. Development участвует в выборе, поэтому его MAE не независимый.

Четыре кандидата основной модели: depth 4/6 × direct/residual; два кандидата fallback:
depth 4/6, direct. Верхний предел 600 деревьев, learning rate 0,05, early stopping 70,
MAE loss. Выбран residual depth=4 / 368 деревьев и fallback depth=6 / 293 дерева.
Обе финальные модели обучены на всём real train. Test не использовался для подбора.

44 причинных числовых признака, без ID и фактического расписания. Fallback исключает
`cur_dev_s`. Одна функция признаков работает с полным CSV и уже доступным префиксом.

| Набор / предиктор | MAE, с |
|---|---:|
| Development: baseline cur_dev | 98,5331 |
| Development: выбранный кандидат | 87,9011 |
| Test: ноль | 103,3371 |

Снижение ошибки относительно cur_dev: **15,29%**. Test — 353 точки, 13 ТС.
MAE late — 139,7203 с, early — 107,3968 с, ontime — 48,8048 с: хвосты задержек
остаются слабым местом, средняя метрика не описывает все случаи.

Полный локальный train/select/evaluate занял 3.163 с.
Один batch predict на 353 готовых feature rows: 1.331 мс;
загрузка/подготовка test inputs и features: 0.318 с.
Это одиночные диагностические замеры, **не** p95, нагрузочный benchmark или NDTP→UI latency.

## Ограничения

Test разделяет период/ТС с train и traffic/план с validate; это benchmark раздачи,
а не независимый следующий день. Групповой holdout, польза синтетики, reconstructed
cur_dev, вероятность/калибровка и потоковая инфраструктура ещё не реализованы.
Опережать фактическое событие в live пока не демонстрировалось. Неизвестный MAE_TARGET
не позволяет переводить локальный MAE в обещание платформенного score.

Повторение: из корня `python -m transport_ml train --model artifacts/new-run` в установленном
окружении. Первый запуск сохранён; после точечного исправления наносекундного horizon
финальный запуск повторён без смены split/кандидатов, MAE и CSV остались теми же.
