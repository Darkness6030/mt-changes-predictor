# ML v4: рецепт v3, дообученный на всей разметке

Те же шесть CatBoost-моделей, признаки (schema 2, 73) и веса, что в v3, **без перенастройки**.
Отличие одно: обучение на всех реальных размеченных точках — train (1141) + test (353) =
1494. Синтетические ТС и факты расписания не используются (см. PROGRESS, ML-IMPROVE-18).

Решение принято до обучения v4 по проверке `ml/experiments/improve18_test_refit.py`:
test делится на 5 частей, каждая предсказывается рецептом, обученным на train без test
и на train + остальные части test.

| Отложено | Модель | Только train | Train + test |
|---|---|---:|---:|
| Точки вперемешку (как validate) | с подсказкой | 70,67 | **67,87** |
| Точки вперемешку | без подсказки | 83,27 | **80,12** |
| Целые ТС | с подсказкой | 70,67 | **69,60** |
| Целые ТС | без подсказки | 83,27 | **81,89** |

Ограничения: test вошёл в обучение, поэтому прямой test MAE для v4 не публикуется, а
replay-метрики дашборда на test для v4 оптимистичны (in-sample). Один день, 13 ТС;
перенос на другой день не доказан. Классификаторы вероятности — из v2 без изменений.

- `main-*.cbm`, `fallback-*.cbm`, `late*.cbm`, `manifest.json`, `recipe.json`, `training.json`.
- `metrics.json` — оценка вне фолдов, а не in-sample.
- `submission.csv` — 151 прогноз validate; `submission.manifest.json` — контрольные суммы.

Воспроизведение: `.venv/bin/python -m transport_ml train-recipe --model artifacts/v4
--recipe ml/experiments/improve18-recipe-v4.json`, затем `predict --model artifacts/v4`.
Каталог зафиксирован; новые эксперименты писать в `artifacts/`.
