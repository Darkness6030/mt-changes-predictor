# ML v5: регрессия v4 и новая вероятность опоздания

**Регрессия — файлы v4 без изменений** (`main-*.cbm`, `fallback-*.cbm` побайтово равны v4),
поэтому `submission.csv` совпадает с v4. Изменены только классификаторы
`P(задержка > 120 с)`: вместо классификаторов v2 (44 признака schema 1, калибровка на
development того же дня) — CatBoost на 73 признаках schema 2, обученный на всех реальных
размеченных точках train + test, Platt по пятифолдовым out-of-fold оценкам.

Рецепт зафиксирован до проверки (`ml/experiments/improve18_late_classifier.py`): глубина 4,
300 деревьев, lr 0,05, L2 5. Проверка вне фолдов на тех же 5 частях test, что и регрессия:

| Режим | Brier v2 → v5 | ROC-AUC v2 → v5 | Brier базовой частоты |
|---|---:|---:|---:|
| С подсказкой | 0,1395 → **0,1065** | 0,818 → **0,895** | 0,1843 |
| Без подсказки (поток) | 0,1763 → **0,1162** | 0,694 → **0,878** | 0,1843 |

Надёжность по корзинам (предсказано → наблюдалось) — в `metrics.json`; отличия в пределах
шума малых корзин. Ограничения те же, что у v4: один день, 13 ТС, test вошёл в обучение
итоговой модели, поэтому прямой test-скор не публикуется.

Сборка: `PYTHONPATH=ml/experiments .venv/bin/python ml/experiments/improve18_build_v5.py
artifacts/v5`. Каталог зафиксирован; эксперименты писать в `artifacts/`.
