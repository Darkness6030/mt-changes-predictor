# ML v8: v6 + обучаемый «нулевой» гейт (hurdle)

Регрессоры и классификаторы вероятности — те же, что в [v6](../v6/README.md): 3 из v4 и
3 из trip-модели с весом 1/6, вероятность из v5. Добавлен `zero_gate.cbm`: CatBoost-
классификатор P(задержка ровно 0) на тех же 82 причинных признаках. Обучен на данных
trip-рецепта: real train+test и синтетика без копий моментов validate.
Если P > 0,5, main-прогноз равен 0: для MAE оптимальна условная медиана, и при такой
вероятности она равна нулю. Порог 0,5 взят из теории, а не подобран по скору.
Fallback (без подсказки) гейт не меняет.

Почему это работает: при `cur_dev_s` = 0 цель ровно 0 в 72% случаев (в train и в test
одинаково), в остальных — в 4%. Регрессоры усредняли такие строки с ненулевыми.
Факты расписания и `manual_fill` не читаются.

Аудит без test labels (все части обучены только на train): test main 67,82 → **67,28 с**;
среди обнулённых 24 точек 95,8% — ровно 0. В validate доля `cur_dev_s` = 0 выше (24%
против 11%): гейт обнуляет 23 из 151 прогноза. Platform score v8: **0,95394** (27.09 22:46 МСК).
Сборка: `improve13_build_v6.py --trip <trip> --zero-gate --output ml/pretrained/v8`.
