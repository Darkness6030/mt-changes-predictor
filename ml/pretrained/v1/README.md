# Зафиксированный ML v1

Готовая версия для команды. Основная модель — MAE test 79,0874 с; fallback — 87,3271 с.
`submission.csv` — готовый файл для Data Science (151 прогноз), ещё не отправленный на платформу.

Не менять содержимое на месте. Эксперименты и повторные CSV сохранять в `artifacts/<run>/`.
Команды установки и запуска — в [ML README](../../README.md).

`manifest.json` содержит checksum обеих `.cbm` и исходников. Его `git_head` — базовый коммит
на момент обучения до публикации ML-кода; фактическую версию обучения определяют
`code_sha256`, `data_sha256`, конфигурация и версии среды. Не переписывать provenance
после создания нового коммита. `submission.manifest.json` фиксирует checksum CSV и manifest.
