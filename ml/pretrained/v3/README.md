# ML v3: причинный контекст расписания и ансамбли

Основная регрессия и автономная регрессия — по три CatBoost MAE с равными весами.
73 общих признака (schema 2); main использует supplied `cur_dev_s`, fallback — отдельные
GPS/плановые признаки без подмены supplied-подсказки. Native модели малы и работают на CPU.

На 353 test-точках: **MAE 71,7707 с** с подсказкой и **83,7950 с** без неё;
v2: 79,0874 / 87,3271 с. В периодическом event-time replay без прогнозных точек:
91,1775 с против 100,4563 с у прежней GPS-estimated + fallback логики.
Это разные протоколы одного дня, не независимая оценка на следующем дне.

Классификаторы вероятности и Platt-калибровка **сохранены из v2**. Их качество не стало
лучше вследствие замены регрессии; статус остаётся `fitted_on_development`.

- `main-*.cbm`, `fallback-*.cbm` — по три члена ансамбля.
- `late.cbm`, `late_fallback.cbm` — неизменённые классификаторы v2.
- `manifest.json`, `recipe.json`, `training.json` — конфигурация, происхождение и hashes.
- `metrics.json`, `test_predictions.csv`, `split.csv`, `*_importance.csv` — результаты.
- `submission.csv`, `submission.manifest.json` — 151 прогноз validate и контрольные суммы.
