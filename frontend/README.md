# Frontend

React / TypeScript / Vite / Leaflet. Очередь рисков, карта, карточка ТС,
управление replay и системная панель. Docker отдаёт сборку через nginx на порту 8080.

```bash
npm --prefix frontend ci
npm --prefix frontend run dev
npm --prefix frontend run build
```

Dev-прокси направлен на Backend `localhost:8010`; полный запуск и данные:
[корневой README](../README.md), [DEMO](../docs/DEMO.md).

Цвет отражает знаковую задержку по серверным порогам, вероятность показывается отдельно.
Участок — два соседних плановых посещения с интервалом до 30 минут. Цветная прямая
является схемой подхода к целевой остановке, а не дорожным маршрутом.

При отказе ML последний прогноз остаётся с возрастом; ack доступен только для
актуального инцидента той же цели и прогона. При сбросе прогона выбор ТС очищается.
Ошибка detail не замораживает основные данные карточки: они берутся из snapshot.
GET-запросы имеют таймаут 5 с; при потере Backend виден возраст последнего snapshot.
Автоматических браузерных E2E-тестов пока нет; сборка проверяет TypeScript.

В историческом replay используется компактная линейка с делениями времени: синий фон
и две границы обозначают выбранный диапазон, красная метка — текущее время источника.
Default — весь `source_window`. Клик по линейке перематывает в выбранный момент; границы
можно перетаскивать отдельно, выделение целиком — сдвигать. Клавиатура: стрелки на
шкале перемещают время на секунду, Home/End — к границам; на границах стрелки меняют
диапазон на минуту. «−/+» меняют масштаб отображения, «К текущему» центрирует шкалу.

Поле диапазона открывает выбор точных дат; кнопка с красной меткой и временем — точный
переход до секунд. Быстрые интервалы: 15м, 1ч, 6ч и «Всё»; стрелки сдвигают диапазон
на его длину. Если новое окно не содержит текущее T, применению сопутствует seek к началу.
Каждый seek восстанавливает причинную историю, очищает предыдущие прогнозы/алерты
и ставит время на паузу; «Продолжить» сохраняет выбранную скорость. Диапазон/масштаб
сохраняются при seek; reload возвращает весь период. Линейка и выбор даты свободно
двигаются в обе стороны за пределы данных; если метка T уходит за видимую линейку,
она центрируется вокруг неё. Выбор диапазона не останавливает проигрывание на правой
границе. Вне source_window карта/очередь пустые, красное сообщение «Нет данных»
появляется в постоянной строке шапки, не меняя высоту панелей.

Календарные поля датасета не переводятся в timezone браузера. Шапка replay содержит
только паузу и свежесть; время/диапазон/скорость находятся внизу. В NDTP перемотка недоступна.

Двойное нажатие на строку ТС в очереди выбирает карточку и вписывает его плановый
маршрут, текущий участок и позицию в карту. Одиночное нажатие сохраняет масштаб.
Объекты карты обновляются на месте: подсказки при наведении не исчезают из-за polling.

На автобусе внешний цветной контур обозначает текущее GPS-отклонение на последней
распознанной остановке; заливка — прогноз к целевой остановке, линия сохраняет его цвет.
Белый внешний ореол выделяет выбранное ТС. Серая пунктирная обводка означает отсутствие
или устаревание оценки, а не движение в графике. Подсказка и карточка показывают оба
значения отдельно, время/возраст текущей оценки и её остановку. Маркер состоит из трёх
постоянных canvas-полигонов; позиция/курс/стиль обновляются только при изменении,
подсказка не пересоздаёт слои. Старый Backend без нового поля даёт серую обводку.

ТС отображаются стрелками по `position.heading_deg` (0° — север, 90° — восток).
При неизвестном или невалидном курсе используется ромб; направление не выдумывается.
Курс подписан в подсказке, при нулевой скорости добавляется «ТС стоит». Размер стрелки
сохраняется при масштабировании карты; обработчик масштаба удаляется вместе с маркером.
