# Frontend

React / TypeScript / Vite / Leaflet. Очередь рисков, карта, карточка ТС,
управление replay и системная панель. Docker отдаёт сборку через nginx на порту 8080.

```bash
npm --prefix frontend ci
npm --prefix frontend run dev
npm --prefix frontend run build
```

Dev-прокси направлен на Backend `localhost:8010`; полный запуск и данные:
[корневой README](../README.md), [DEMO](../docs/DEMO.md).

Цвет отражает знаковую задержку по серверным порогам, вероятность показывается отдельно.
Участок — два соседних плановых посещения с интервалом до 30 минут. Цветная прямая
является схемой подхода к целевой остановке, а не дорожным маршрутом.

При отказе ML последний прогноз остаётся с возрастом; ack доступен только для
актуального инцидента той же цели и прогона. При сбросе прогона выбор ТС очищается.
Ошибка detail не замораживает основные данные карточки: они берутся из snapshot.
GET-запросы имеют таймаут 5 с; при потере Backend виден возраст последнего snapshot.
Автоматических браузерных E2E-тестов пока нет; сборка проверяет TypeScript.

В историческом replay доступна временная шкала и ввод точной даты/времени (до секунд).
Отпускание ползунка или кнопка «Перейти» восстанавливает историю до выбранного момента,
очищает прежние прогнозы/алерты и ставит время на паузу. «Продолжить» возобновляет
проигрывание с сохранённой скоростью. Время сохраняет календарные значения датасета,
без перевода в timezone браузера. В NDTP перемотка недоступна.

Начало и конец диапазона навигации задаются отдельными полями даты/времени; default —
весь доступный `source_window`. Ползунок и точный переход работают в выбранном диапазоне.
«Применить диапазон» переносит к началу на паузе, если текущий момент вне новых границ;
«Весь период» возвращает исходную шкалу. Диапазон сохраняется при seek/reset в вкладке,
но не ограничивает автоматическое проигрывание: при выходе за него показано предупреждение.
Шапка replay показывает только паузу и свежесть, дата/время/скорость находятся внизу.
